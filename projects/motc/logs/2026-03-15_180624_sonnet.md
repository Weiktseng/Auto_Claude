## 核心架構：Intent Router

用戶問題 → 意圖判斷器(Router) → 分流到不同工具：
- FAQ/法規 → RAG 知識庫
- 個人資料查詢 → 監理 API（汽燃費/定檢/違規）
- 客運路線 → TDX API
- 即時路況 → 省道即時 API / 高速公路 API
- 業務導引 → 流程樹
- 多語言 → LLM 翻譯
- 轉真人 → 客服系統
