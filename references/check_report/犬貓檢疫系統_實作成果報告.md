## 一、摘要

在約 **半天（~6 小時）** 內，我們基於既有的 myReAct 多機構子應用架構，從零建立了犬貓檢疫智慧客服的完整 PoC，包含：

- 完整的子應用程式碼（19 支 Python 檔案，3,600+ 行）
- 77 筆官方 FAQ 知識庫（含 PDF 批次匯入）+ 172 條法規全文
- 4 支自動化資料腳本（Playwright 爬蟲 + PDF FAQ 匯入 + 法規匯入 + RAG 初始化）
- 3 套測試程式（功能 107 項 + 瀏覽器 E2E 36 項 + LLM 品質評分 78 題）
- **回應速度 4,090ms（達標 ≤5,000ms）**，品質評分 4.38/5.00（良好等級）
- 經 4 次迭代優化：速度從 6.2s 降至 4.1s（-34%），知識庫從 53 筆擴充至 77 筆

## 三、實作架構

### 3.1 系統架構

```
使用者 ─→ 嵌入式 Widget (iframe) ─→ FastAPI 應用層 (petq/)
                                       │
                                       ├─ Intent Router（Fast RAG / ReAct 分流）
                                       ├─ PetqReActAgent（多輪對話推理）
                                       ├─ RAG 知識庫（ChromaDB + BM25 Hybrid Search）
                                       ├─ Graph RAG（知識圖譜增強檢索）
                                       ├─ 人機轉接偵測
                                       └─ LLM API（GPT-4.1-mini）
```

### 3.2 子應用隔離

| 維度 | 隔離方式 | 驗證 |
|------|---------|------|
| 程式碼 | 獨立 `petq/` 目錄 | ✅ |
| 向量庫 | `./petq/data/chroma/` | ✅ 測試驗證 |
| 資料庫 | `./petq/data/conversations.db` | ✅ |
| 工具 | `category="petq"` 註冊 | ✅ 6 個工具全隔離 |
| Prompt | 獨立 `prompt_template.py` | ✅ 不含其他子應用資訊 |
| 前端 | 獨立 HTML + 品牌色（農業部綠 #2e7d32） | ✅ |

#### 評分模型的主要回饋

**優點：**
- 語言品質完美 5.0/5 — 繁體中文無簡體、格式清晰
- 情境模擬表現最佳（4.8/5）— 複雜多步推理能力強
- hard 難度題得分最高（4.7/5）— ReAct Agent 推理能力出色
- 範圍外問題拒答精準，不會胡說
- 回應速度 4,090ms ✅ 達標（需求 ≤5,000ms）

**待改進：**
- NVRI 分類偏低（3.7/5）— 獸醫研究所操作細節的 FAQ 覆蓋度不足
- 來源引用 3.73/5 — Prompt 已強化引用要求，但 Fast RAG 路徑回答較簡短，引用較少
- easy 題分數反而最低（4.0/5）— Fast RAG 路徑回答簡短，具體細節不足
- 改進方向：(1) NVRI FAQ 獨立精細化切分 (2) Fast RAG prompt 加強引用格式 (3) easy 題考慮 fallback 到 ReAct

#### 迭代優化歷程

| 版本 | FAQ | 回應速度 | 總分 | 主要變更 |
