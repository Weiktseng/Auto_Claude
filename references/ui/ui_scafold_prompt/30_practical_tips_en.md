# Steve Schoger — 30 Practical UI Design Tips

Source: digitalsynopsis.com + Twitter tips

---

1. **Subtle call-to-action for negative actions** — Use understated links rather than prominent buttons for delete/cancel, always include a confirmation step.

2. **Use fewer borders** — Reduce visual clutter by replacing borders with box shadows, contrasting background colors, or extra spacing.

3. **Align text consistently** — Proper alignment makes designs cleaner and content much more scannable.

4. **Saturate grey text on colored backgrounds** — Add a hint of the background hue to grey text for better visual harmony.

5. **Add subtle shadows behind white text** — Gentle shadows on bright backgrounds enhance legibility and make text pop.

6. **Style icons within shapes** — Rather than enlarging small icons for landing pages, place them within shapes and apply background colors.

7. **Saturate your greys** — Move beyond plain grey by infusing grey tones with blue or brown for cooler or warmer aesthetics.

8. **Balance text weight across sizes** — Make larger text thinner and smaller text bolder to create visual weight consistency.

9. **Hero banner trick** — Combine desaturated photos with bold colors and multiply blend modes for high contrast text areas.

10. **Overlap elements to create depth** — Layer elements strategically to create depth and encourage user scrolling.

11. **Offset box shadows vertically** — Apply slight vertical offsets for more natural-looking shadow effects.

12. **Use lighter icons for inactive states** — When icons are weightier than surrounding text, use lighter icon weights.

13. **Replace bullets with checkmarks** — Use arrows or checkmarks instead of standard bullets for visual interest in lists.

14. **Add a color band on top** — A 4-6px color strip at the top of hero sections increases design liveliness.

15. **Use subtle contrast instead of keylines** — Distinguish sections through background color differences rather than divider lines.

16. **Shift gradient hues** — Rotate hues by 10-20 degrees to make gradients appear more vibrant.

17. **16px font, 1.5 line height** — A reliable default combination for body copy readability.

18. **Add letter-spacing to all-caps** — Extra spacing in uppercase text improves readability and provides breathing room.

19. **Style form inputs consistently** — Apply consistent, thoughtful styling details across all input components.

20. **Make your own map style** — Create stylish maps without requiring advanced graphic design skills.

21. **Use keylines to connect content** — Keylines both divide and visually connect separate content areas.

22. **Define spacing with multiples** — Establish spacing using mathematical multiples (4/8/12/16/24/32...) for vertical rhythm consistency.

23. **Use two-column form layout** — Organize lengthy forms into two columns to better utilize wide screens.

24. **Use font weight and color for emphasis** — Leverage color and font weight instead of solely increasing font size.

25. **Adjust line-height proportionally** — Tighten line-height as text size increases; avoid uniform line-height across sizes.

26. **Design better tables** — Right-align numbers, add alternating row colors, and use appropriate whitespace.

27. **Style content blocks** — Card-based design gives content more structure and visual organization.

28. **Dropdowns as flexible containers** — Design dropdown menus with two-column layouts and supporting text.

29. **Use borders on overlapping images** — Add background-matching borders to overlapping images for visual clarity.

30. **Think outside the database** — Present field-value data creatively rather than using one-to-one database mapping to the interface.
