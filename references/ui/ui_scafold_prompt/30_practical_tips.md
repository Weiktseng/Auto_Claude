# Steve Schoger — 30 個實用 UI 設計 Tips

來源：digitalsynopsis.com 整理 + Twitter tips

每一條都是可以直接套用的建議：

---

1. **負面操作用低調連結** — 刪除/取消用淡色文字連結，不要用醒目按鈕，加確認步驟
> Use understated links for negative actions — subtle links rather than prominent buttons for delete/cancel, always include a confirmation step.

2. **減少邊框** — 用 box shadow、對比背景色、增加間距取代邊框
> Use fewer borders — replace borders with box shadows, contrasting background colors, or extra spacing to reduce visual clutter.

3. **對齊文字** — 統一對齊方式讓版面更乾淨、更好掃讀
> Align text consistently — proper alignment makes designs cleaner and content much more scannable.

4. **彩色背景上的灰字加色相** — 灰字加入背景的色相會更和諧
> Saturate grey text on colored backgrounds — add a hint of the background hue to grey text for better visual harmony.

5. **白字加微妙陰影** — 亮背景上的白字加淡影提高易讀性
> Add subtle shadows behind white text — gentle shadows on bright backgrounds enhance legibility and make text pop.

6. **圖標放在形狀裡** — 小圖標要放大時，套在有背景色的形狀裡
> Style icons within shapes — rather than enlarging small icons, place them within shapes and apply background colors.

7. **灰色加飽和度** — 灰色加入藍色或棕色調會更有溫度
> Saturate your greys — move beyond plain grey by infusing grey tones with blue or brown for cooler or warmer aesthetics.

8. **不同大小文字的視覺重量** — 大字用細體、小字用粗體
> Balance text weight across sizes — make larger text thinner and smaller text bolder to create visual weight consistency.

9. **Hero banner 技巧** — 去飽和照片 + 粗體色塊 + multiply 混合模式
> Hero banner trick — combine desaturated photos with bold colors and multiply blend modes for high contrast text areas.

10. **重疊元素創造深度** — 讓元素互相重疊引導使用者往下捲
> Overlap elements to create depth — layer elements strategically to create depth and encourage user scrolling.

11. **Box shadow 偏移** — 垂直偏移些微值讓陰影更自然
> Offset box shadows vertically — apply slight vertical offsets for more natural-looking shadow effects.

12. **非活動圖標用淡色** — 圖標比文字重時用較淡的版本
> Use lighter icons for inactive states — when icons are weightier than surrounding text, use lighter icon weights.

13. **用勾勾取代項目符號** — 清單用箭頭或勾勾更有視覺趣味
> Replace bullets with checkmarks — use arrows or checkmarks instead of standard bullets for visual interest in lists.

14. **頂部色帶** — Hero 區域頂端加 4-6px 色帶增加活力
> Add a color band on top — a 4-6px color strip at the top of hero sections increases design liveliness.

15. **微妙對比取代分隔線** — 用背景色差異區分區塊
> Use subtle contrast instead of keylines — distinguish sections through background color differences rather than divider lines.

16. **漸層色相偏移** — 漸層的色相偏移 10-20 度更鮮豔
> Shift gradient hues — rotate hues by 10-20 degrees to make gradients appear more vibrant.

17. **16px + 1.5 行高** — 內文預設值
> 16px font, 1.5 line height — a reliable default combination for body copy readability.

18. **大寫加 letter-spacing** — 全大寫文字加字距增加可讀性
> Add letter-spacing to all-caps — extra spacing in uppercase text improves readability and provides breathing room.

19. **表單元件一致樣式** — 所有 input 元件套用統一設計
> Style form inputs consistently — apply consistent, thoughtful styling details across all input components.

20. **自製地圖樣式** — 不需要進階設計技能也能做好看的地圖
> Make your own map style — create stylish maps without requiring advanced graphic design skills.

21. **Keyline 連接內容** — 分隔線同時有「分」和「連」的功能
> Use keylines to connect content — keylines both divide and visually connect separate content areas.

22. **倍數間距系統** — 用 4/8/12/16/24/32... 的倍數維持節奏
> Define spacing with multiples — establish spacing using mathematical multiples (4/8/12/16/24/32...) for vertical rhythm consistency.

23. **長表單雙欄排版** — 善用寬螢幕避免過長的輸入框
> Use two-column form layout — organize lengthy forms into two columns to better utilize wide screens.

24. **用字重和顏色做強調** — 不要只靠放大字體
> Use font weight and color for emphasis — leverage color and font weight instead of solely increasing font size.

25. **行高隨字體大小調整** — 大字行高緊、小字行高鬆
> Adjust line-height proportionally — tighten line-height as text size increases; avoid uniform line-height across sizes.

26. **表格設計** — 對齊數字靠右、加交替行顏色、適當留白
> Design better tables — right-align numbers, add alternating row colors, and use appropriate whitespace.

27. **內容區塊樣式** — 卡片式設計讓內容更有結構
> Style content blocks — card-based design gives content more structure and visual organization.

28. **Dropdown 當容器** — 下拉選單可以有雙欄、輔助文字
> Dropdowns as flexible containers — design dropdown menus with two-column layouts and supporting text.

29. **重疊圖片用邊框** — 重疊圖片加與背景同色的邊框增加清晰度
> Use borders on overlapping images — add background-matching borders to overlapping images for visual clarity.

30. **跳脫資料庫思維** — 欄位-值的呈現可以更有創意，不必照搬 DB schema
> Think outside the database — present field-value data creatively rather than using one-to-one database mapping to the interface.
