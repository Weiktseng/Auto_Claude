## 六、技術說明

### 評測方法
1. **L1 評測**：Playwright E2E → 模擬真實使用者操作 → LLM 5 維度評分
2. **L2-L5 評測**：直接呼叫 API → LLM 5 維度評分（10 倍速度提升）
3. **評分模型**：{{模型名稱}}（temperature=0，確保可重現）
4. **抽樣方法**：分層隨機抽樣，確保各分類覆蓋

### 評分維度定義
- **正確性**：資訊是否與官方規定一致，有無捏造
- **完整性**：是否涵蓋該問題所需的全部關鍵資訊
- **來源引用**：是否引用法規條文、官方來源
- **語言品質**：語言流暢自然，符合目標語系
- **實用性**：使用者能否根據回答直接採取行動

### 評分來源透明度

| 環節 | 來源 | AI 參與度 |
|------|------|----------|
| L1 題目 | 官方 FAQ 改寫為口語 | 改寫語氣，不改內容 |
| L1 標準答案 | 官方 FAQ 原文 | **零** — 一字未改 |
| L2 題目 | 同一知識點多種問法 | AI 模擬用戶口語 |
| L3 題目 | 法規原文出題 | AI 從法規出題，標明條號 |
| L3 標準答案 | 法規條文原文 | **零** — 直接引用 |
| L4 題目 | 範圍外/虛構資訊 | 手動設計 |
| L5 題目 | 口語/錯字/方言 | AI 模擬真實用戶語料 |
| 評分 | LLM（temperature=0） | 有明確 RUBRIC（5 維度 × 5 級距） |
| 評分理由 | 每題輸出 strengths / weaknesses | 可追溯，可人工覆核 |
